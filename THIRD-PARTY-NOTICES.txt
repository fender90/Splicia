=======================================================================
FFmpeg 8.1
=======================================================================

The ffmpeg folder holds FFmpeg's libraries (avcodec, avformat, avutil, avfilter, avdevice,
swscale, swresample) and ffmpeg.exe, from the "gpl-shared" Windows build of FFmpeg 8.1 by
BtbN/FFmpeg-Builds. That build includes GPL components (such as x264 and x265), so it is
licensed under the GNU General Public License version 3; the full text is in
ffmpeg\LICENSE.txt. FFmpeg is a trademark of Fabrice Bellard.

Splicia runs these files unmodified. Their source code is available from:
  FFmpeg:         https://ffmpeg.org/download.html  (git: https://github.com/FFmpeg/FFmpeg, release/8.1)
  Build scripts:  https://github.com/BtbN/FFmpeg-Builds  (lists every library in the build and its source)
